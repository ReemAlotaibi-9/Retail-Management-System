Retail Management System

A Python-based academic project developed for CECS218 at the University of Jeddah.

Overview

An interactive console application for managing customers, products, memberships, inventory, and orders.

Features

* Customer, Member, and VIP Member management
* Product and bundle management
* Inventory tracking
* Order processing and membership discounts
* File handling and data validation
* Custom exception handling

Technologies

* Python
* Object-Oriented Programming (OOP)
* File Handling
* Exception Handling
